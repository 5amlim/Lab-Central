# Archived PATHFAST chest-pain decision explorer

Archived on 2026-10-30. These JavaScript files preserve the previous clickable decision tree and historical PATHFAST reference criteria for reference and rollback only. They are **not loaded** by the live website.

The active `pathfast-clinical.js` renders static visual pathway references for both 0/1-hour and 0/2-hour use. The active `pathfast-interactive.js` still supplies RN timing and specimen interference tools, but its legacy `flow()` decision explorer is no longer invoked from the chest-pain page.

Do not treat these archived clinical thresholds as an approved current medical protocol.
